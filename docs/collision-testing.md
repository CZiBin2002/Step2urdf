# 碰撞与零点改进验证

验证日期：2026-11-11。

## 已实现行为

- 新建 Link 默认采用凸分解碰撞体，已有工程可一键生成。显示、运动检查和凸分解导出使用同一套体积；合并视觉 STL 不合并凸体。
- 滑杆与数值输入通过后端检查整段运动，按当前间隙和最大展开半径保守推进，在首次接触前停止。
- 从零位按几何扫描旋转/滑动行程，可替换默认 ±1.57 rad 等数值限位。相邻运动 Link 也参加检测。
- CAD 中已贴合或重叠的相邻凸体对可作为装配配合排除，其余凸体对继续检测。工程支持切换到严格深度模式。
- 改零点只平移坐标和两个限位端点；实际几何姿态、总行程及导出后的六轴正运动学保持一致。

## 回归验证

Python：16 个用例通过；JavaScript：2 个用例通过。前端生产构建通过。

覆盖：途中碰撞但终点无碰撞、0.1 mm 薄障碍物、旋转和滑动限位、mimic 限位、固定刚体、相邻运动 Link、无关 Link 初始碰撞、装配配合仅排除具体凸体对、凹形支架开口、亚毫米凸体闭合、重复改零点、六轴非平行转轴正运动学、URDF/MJCF/USD 导出及碰撞 API 缓存。

本机内置 Atlas R6 示例的 5 个关节完整几何扫描约 7.9 秒（已缓存碰撞体）。浏览器验证包括碰撞体显示、滑杆运动、设置新零点、重新计算限位。速度受零件数量、几何复杂度和接触状态影响。

页面实测：肘关节可输入 `-1.8 rad`，越过原默认 `-1.57 rad`。碰撞扫描得到 `[-4.325812, 1.058023] rad`；在 `-1.8 rad` 处重新设零后显示 `[-2.525812, 2.858023] rad`，总行程均为 `5.383835 rad`，姿态保留。截图保存在 `exports/a3-collision-check/workbench-validation.png`，截图为内置示例。

## 使用边界

几何限位是在零位固定其他关节得到的截面，多关节联动继续进行碰撞检查。扫描不会推断舵机硬限位和电缆行程。最大尺寸不超过 15 mm 的零件使用保守凸包，小孔可能填充；较大凹形结构采用近似凸分解。导出后的碰撞响应由仿真器负责。
