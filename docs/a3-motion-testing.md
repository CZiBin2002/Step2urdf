## 碰撞模型与发现的问题

运动工程使用外壳、支架、底座外轮廓和夹持面，共 1,349 个凸碰撞体。舵机内部齿轮、轴承滚动配合和内部电子器件保留视觉与质量信息。夹指根部 14 mm 的啮合/铰接区域从外部碰撞代理中分离，末端夹持面继续检测碰撞。相同碰撞代理直接写入 URDF。

实际 STEP 测试复现并修复了两个转换问题：

1. 粗略凸分解侵入轴承盖中心孔，导致底座只转动几度便被误判碰撞。现在根据 CAD 同轴内外圆特征生成角扇区凸体，保留中心孔；底座可整圈试转。
2. URDF 没有根 Link 的 origin 属性，原导出未保留 CAD 到世界坐标的朝向。现在固定底座存在非单位根变换时添加 world 固定参考关节，导出后仍然竖直向上。

碰撞检测增加接触容量，并在引擎接触数组不足时明确报错。本次完整测试的接触容量警告为 0。

## 指定零位

世界坐标为 Z 向上、X 朝前。大臂、小臂及夹爪中轴的计算方向均为 `(0, 0, 1)`，夹爪正面方向为 `(1, 0, 0)`，误差小于 `1e-8`。

“半开”按闭合到几何最大开口的**宽度 50%**计算：

- 几何最大开口：约 **130.37 mm**。
- 新零位开口：约 **65.21 mm**。
- 开口比例：**0.500000**。

原 CAD 夹爪闭合处有轻微几何相交。工作台恢复 CAD 零位前会检查行程和碰撞，不会把有效零位替换成无法试转的原始姿态。

## 在该零位扫描的几何行程

以下数值均相对于新的竖直、半开零位，其他关节固定在该零位。工作台内部及 URDF 使用弧度，此处换算为角度。

| 关节 | 下限 | 上限 |
| --- | ---: | ---: |
| 底座旋转 | -180.00° | 180.00° |
| 大臂俯仰 | -78.33° | 95.76° |
| 小臂俯仰 | -114.22° | 96.19° |
| 腕部俯仰 | -77.87° | 99.02° |
| 腕部旋转 | -180.00° | 180.00° |
| 夹爪开合 | -34.42° | 58.83° |

底座及腕旋转扫描未遇几何阻挡，以上各显示一整圈。其他边界均验证了越界后发生碰撞。多关节联动继续检查完整运动路径。

这些是当前碰撞模型的几何范围，不推断舵机编码器、电缆和硬止挡参数；本次未连接真实机械臂。

## 验证结果

- 六个独立关节共 54 个行程内采样姿态无碰撞；8 个有接触的边界完成越界检查。
- 在 3 个零位参考下重复重设零点，8 个刚体的姿态与各关节总行程保持一致。
- URDF 中 8 个合并视觉网格和 1,349 个碰撞体资源均存在且非空。
- 导出零位的关节坐标与视觉采样匹配，最大采样位置误差约 `7.1e-9 m`，双夹指 mimic 保留。
- 16 项 Python 回归、2 项 JavaScript 回归及前端构建通过。
- 页面使用实际 A3 工程验证底座 `0 → 0.5 rad → 0`，并确认六个读数回零、夹爪保持半开；恢复不可用的原 CAD 零位时保留当前有效零位。浏览器没有脚本错误。
