# Step2URDF

Step2URDF 是本地运行的机器人 CAD 工作台。导入 STEP 装配后，可以在 3D 视图中把零件分成刚体（Link），配置关节和零位，再导出 URDF、MJCF、USD 或强化学习工程。

## v0.2.0

新增可选的 **精简 URDF 网格** 导出，用于减少 Jetson Nano 等设备需要加载的三角面。已有用户拉取更新后，重新运行 `start.cmd` 即可安装新增依赖并构建前端。

## 安装与启动

以下命令适用于 Windows PowerShell。先安装 Git、64 位 Python 3.13 和 Node.js 22.12 或更新的受支持版本。安装后可用 `python --version` 和 `node --version` 检查环境。

```powershell
git clone https://github.com/CZiBin2002/Step2urdf.git
cd Step2urdf
.\start.cmd
```

也可以在资源管理器中双击 `start.cmd`。脚本会准备 `.venv`、安装依赖、构建前端并启动服务。前端依赖清单未变时，脚本会复用已安装的包。如果现有 `.venv` 无法运行，脚本会将它备份为 `venv.bak` 后重建。

服务启动后，在浏览器打开 [本地工作台](http://127.0.0.1:8765/)。首次打开会载入 Atlas R6 示例。按 Ctrl+C 可停止服务。修改前端后，重启 `start.cmd` 即可重新构建。

## 使用教程

### 先用示例试转

1. 打开右侧 **检查器 → 试转**，拖动一个关节的滑杆。3D 视图会显示该关节带动的 Link。
2. 点击 **回到零位**，再打开 **测试与导出**。
3. 勾选 **URDF**，点击 **检查模型 → 下载模型 ZIP**。解压后应看到 `.urdf` 文件和 `meshes/` 文件夹。移动模型时请保留两者的相对位置。

还可以从 **导入模型 → 内置示例** 切换到 Scout 4WD 小车。

复核大装配时，可在 3D 工具栏切换正面、侧面、俯视和斜视，也可全屏预览。摄像头模拟画面单独停靠。**检查器 → 试转** 按身体部位整理运动关节，选中一项可查看父子 Link、轴向并做正反试转。复核勾选记录保存在当前浏览器，修改关节轴、零位或挂接关系后需重新确认。

### 将自己的 STEP 转成 URDF

1. **导入装配。** 点击 **导入模型 → 选择文件**，或拖入 `.step` / `.stp`。已有 URDF、MJCF 和 USD 的模型也可导入。若模型引用外部网格，请用 **选择文件夹** 选入模型与资源，或提供包含它们的 ZIP。缺少资源时可补选文件夹。
2. **分组创建 Link。** 在左侧 **零件** 或 3D 视图中选择零件，按 Shift 或 Ctrl 多选，再点击 **用所选零件创建 Link**。把始终一起运动的零件归到同一个 Link。例如，可把底座板和固定在它上面的紧固件归入 `base_link`，把能绕底座转动的结构归入另一个 Link。也可在右侧零件属性中修改 **所属 Link**。
3. **添加关节。** 在左侧 **关节 → 创建关节** 中选择父 Link、子 Link 和关节类型。在检查器里调整锚点、轴向、限位和动力学参数。**识别转轴** 可根据父子 Link 上的圆柱面提出候选。应用候选后，在 **试转** 中确认轴向和正转方向。位置用米，转角用弧度，例如 30° 约为 `0.524 rad`。
4. **配置碰撞和物理参数。** 新 Link 默认启用凸分解碰撞体。在 **检查器 → 试转** 点击 **为所有 Link 生成碰撞体** 可更新已有工程；再点击 **按碰撞体计算限位**，替换创建关节时的默认行程。视图右上角的 **显示碰撞体** 可以预览与检测、导出共用的碰撞几何。用 **质量与惯量 → 计算** 根据几何和密度估算物理参数，已有实测值时可用 **手动设置**。
5. **保存与导出。** 点击 **保存工程** 下载 `.cad2urdf.json`。可在 **导入模型 → 本地工程缓存** 重新打开缓存，或导入备份继续编辑。在 **测试与导出** 选择格式，先校验模型，再下载 ZIP。校验会检查关节树及所选格式的模型资源。启用合并 STL 时，视觉网格与碰撞网格会按 Link 分别合并。

URDF 的关节树需要一个根 Link，每个子 Link 只能有一个父关节。STEP 的几何和装配关系可用来推断 Link 和转轴。碰撞限位根据几何计算；舵机机械行程、电缆约束和传动关系需要结合实际机构设置。

### 导出精简 URDF

1. 在 **测试与导出** 勾选 **URDF** 和 **精简 URDF 网格**。此选项默认关闭，可与 **每个 Link 合并导出的 STL 网格** 一起使用。
2. 点击 **检查模型 → 下载模型 ZIP**。精简导出包的文件名以 `-simplified.zip` 结尾。解压后保留 URDF 和 `meshes/` 的相对位置。

精简模式会减少视觉与碰撞 STL 的三角面，并复用两者共有的网格。关节、质量、惯量和包围盒碰撞体沿用原工程的数据。网格细节和碰撞轮廓可能随减面略有变化。

将一个含 605 个零件的 STEP 测试装配分到同一个 Link，在关闭 STL 合并时得到以下结果。

| 指标 | 普通导出 | 精简导出 | 降幅 |
| --- | ---: | ---: | ---: |
| 视觉或碰撞网格三角面数（各自） | 1,891,205 | 1,108,735 | 41.4% |
| ZIP 大小 | 58.9 MB | 17.7 MB | 70.0% |

### 设置关节零位

1. 在 **检查器 → 试转** 中拖动滑杆或输入精确数值，将机器人调到希望的起始姿态。例如，先让机械臂竖直，再把夹爪调到开合行程的中点。
2. 点击 **将当前姿态设为零位**。3D 姿态会保留，关节读数会归零。之后试转的数值都相对于这个零位。
3. 导出时，关节原点、轴向及限位会转换到新零位。点击 **回到零位** 可取消临时试转，点击 **恢复 CAD 零位** 可清除自定义零位。

零点改变时，限位两端同时减去零点偏移，总行程保持不变。例如 CAD 行程为 `[-2.9, 2.9] rad`，在 `1.1 rad` 处设零后显示 `[-4.0, 1.8] rad`，实际可达姿态与原来相同。滑杆零点不一定在中间；重新设置零点不会把行程重新裁成对称范围。

### 摄像头预览与导出

在 **检查器 → 摄像头设置** 选择安装 Link，填写相对于该 Link 的位姿、分辨率、水平视场、更新频率与裁剪距离。点击 3D 视图工具栏的相机图标可切换模拟画面。画面随关节试转更新，使用工作台中的 3D 场景。

A3 预设从 STEP 的 `NAUO72` 镜头几何计算安装位置和拍摄方向。URDF ZIP 包含相机坐标系、光学坐标系和 Gazebo Sim RGB 传感器配置。将相机配置随工程保存，便于下次编辑。

### 碰撞体与碰撞限位

- **凸分解**：对每个零件生成多个凸体，保留较大支架和外壳的凹形空隙。最大尺寸不超过 15 mm 的小配件使用保守凸包；其小孔可能被填充。首次生成较慢，结果缓存在 `.projects/collision-cache/`。凸分解碰撞体在导出时始终保持分离，勾选合并 STL 也不会把它们合成一个凸包。
- **网格 / 包围盒**：旧工程可继续使用。网格模式的运动检测采用物理引擎使用的凸包；凹形结构建议切换为凸分解。固定连接的传感器或装饰件可禁用碰撞；参与运动的刚体需要碰撞体。只想核对关节轴向时，可取消勾选 **试转时检查碰撞**，进入运动学预览。
- **实时试转与碰撞检查**：拖动滑杆时，3D 模型实时显示待确认的目标姿态。松手或短暂停顿后，系统检查从最后确认姿态到目标的完整路径。遇到碰撞会回到首次接触边界，默认保留 0.1 mm 间隙。检测失败时回到最后确认的姿态。固定连接视为同一刚体，相邻运动 Link 之间也检查碰撞。
- **CAD 装配重叠**：默认排除 CAD 零位已有重叠或贴合的相邻凸体对，以兼容轴承、转轴等装配配合，其余相邻凸体仍参与检测。工程会保存该策略，限位结果会报告排除数量。可切换 **严格限制重叠深度**，此时原有穿透仅允许额外加深 0.02 mm；保守凸包填孔时此模式可能限制正常转动。无关 Link 的初始碰撞始终阻止试转。
- **计算限位**：在当前零位固定其他关节，向两侧扫描到首次碰撞。旋转关节每侧最多扫描一圈，无碰撞则显示一整圈；滑动关节每侧最多扫描 0.5 m。点击按钮会覆盖已有数值限位，应随后填写真实舵机或电缆行程。多关节联动的可达空间不能由一组独立上下限完全表达，因此试转仍逐段检查碰撞。调整分组、轴向或碰撞体后应重新计算。

碰撞检测用于几何运动预览，闭链约束和真实动力学仍需在仿真器中验证。URDF 本身只保存碰撞几何与关节上下限；导出后的接触响应由所用仿真器处理。

### 导出训练工程

在 **测试与导出 → 生成训练工程** 选择 Isaac Lab 或 MJLab，然后点击 **下载训练工程 ZIP**。解压后按 `TRAINING.md` 安装或启动对应仿真环境，并运行训练脚本。生成的 PPO 示例用于关节姿态跟踪。步态、抓取等任务需要按目标重新定义观测、奖励和终止条件。

## 格式与限制

| 导出格式 | 包内文件 | 约束 |
| --- | --- | --- |
| URDF | `.urdf`、STL 资源 | 支持树结构和线性 mimic。球铰、闭链需选择其他格式。 |
| MJCF | `.xml`、STL 资源 | 支持球铰、闭链和线性关节耦合。 |
| USD | 自包含 `.usda` | 支持球铰及连接或焊接约束。含线性耦合时请选择 URDF 或 MJCF。 |
| Isaac Lab | USDA、`train_isaac.py` | 面向 Isaac Lab 2.3.2、Isaac Sim 5.1 和 Stable-Baselines3。 |
| MJLab | MJCF、`train_mjlab.py` | 面向使用 actor / critic 配置的 MJLab、MuJoCo Warp 和 RSL-RL。 |

格式转换覆盖工作台可编辑的 Link、关节、几何与物理属性。材质纹理、仿真器专用传感器和复杂传动的转换有限。关节滑杆用于运动学预览，闭链约束需要在对应仿真器中验证。

## 常见问题

- **浏览器打不开工作台。** 检查启动终端是否在运行，以及终端显示的端口是否为 8765。修改前端源码后，重新执行 `npm.cmd run build` 并重启服务。
- **3D 区域显示 WebGL 错误。** 用支持 WebGL 的浏览器打开，检查浏览器的图形加速设置。
- **导入 URDF 时提示缺少网格。** 选择包含主文件与网格的目录或 ZIP，保留原来的资源相对路径。
- **导出提示有未分配零件。** 在 **零件 → 仅显示未分配零件** 中检查遗漏，并把希望导出的零件分配到 Link。

CAD、工程缓存和生成文件默认保存在本机。工作台缓存目录为 `.projects/`，可用 **保存工程** 将项目备份到其他位置。

## 接入 AI

检查器的「AI 建议」默认使用本地几何规则。可导出带版本的结构 JSON，或用 `POST /api/projects/{id}/structure` 获取包含装配路径、质心、包围盒及圆柱特征的结构数据。请求体是当前的 Project，API schema 可在本地 `/docs` 查看。

实现一个 Python 函数后，将 `STEP2URDF_ADVISOR` 设为 `模块名:函数名` 并重启服务。函数接收同一份结构 JSON 对应的字典，返回候选列表。建议由用户选择后才应用。

```python
def suggest_links(structure: dict) -> list[dict]:
    assigned = {part_id for link in structure["project"]["links"] for part_id in link["parts"]}
    part = next((item for item in structure["parts"] if item["id"] not in assigned), None)
    if part is None:
        return []
    return [{
        "name": "candidate_link",
        "parts": [part["id"]],
        "origin": part["center"],
        "reason": "将一个未分配零件作为候选刚体",
        "confidence": 0.5,
    }]
```

将上例存为仓库根目录的 `advisor.py`，在启动后端之前执行 `$env:STEP2URDF_ADVISOR = "advisor:suggest_links"` 即可测试接口。若插件调用远程模型，实际发送的结构字段由插件决定。

## 开发

前端位于 `frontend/`，转换与导出服务位于 `workbench/`。启动后端后，在另一个终端执行 `npm.cmd run dev`，打开 Vite 打印的地址。后端运行时，可访问 [本地 API 文档](http://127.0.0.1:8765/docs)。

回归测试与构建：

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements-dev.txt
.\.venv\Scripts\python.exe -m pytest tests -q
node --test tests/motion.test.js
npm.cmd run build
```

对实际 A3 STEP 的全部实体生成碰撞体并验证 URDF 网格资源：

```powershell
.\.venv\Scripts\python.exe -m tests.check_a3 "A3六自由度机械臂-树莓派.STEP"
```

结果保存在 `exports/a3-collision-check/`。此检查将 STEP 作为一个静态装配验证几何完整性；不推定六轴 Link 分组、转轴和机械行程。运动、碰撞边界、薄障碍物、耦合、零点以及 URDF/MJCF/USD 导出由独立回归用例验证。

对提供的 A3 树莓派装配建立真实六舵机工程，并按“大臂、小臂、夹爪均竖直向上，夹爪正面朝前、半开”校准与测试：

```powershell
.\.venv\Scripts\python.exe -m tests.check_a3_motion "A3六自由度机械臂-树莓派.STEP"
```

此专用装配预设包含 5 个机械臂舵机和 1 个夹爪舵机，另一侧夹爪以 `mimic=-1` 跟随。保留全部 517 个视觉实体，碰撞使用外壳、支架和夹持面；内部传动不作为自身关节的障碍。环形盖板保留真实中心孔，夹爪根部啮合齿轮从碰撞体中分离。半开按几何开口宽度的 50% 定义。结果、可编辑工程和 URDF ZIP 保存在 `exports/a3-motion-check/`；详细说明见 `docs/a3-motion-testing.md`。该预设针对这份 STEP 的装配实例编号，不用于任意机械臂。

交互流程参考 [StackForce CAD2URDF](https://cad2urdf.stackforce.cc/upload?workbenchEmbed=1)。Step2URDF 的工程文件独立保存。训练配置参考 [Isaac Lab](https://github.com/isaac-sim/IsaacLab) 和 [MJLab](https://github.com/mujocolab/mjlab) 的公开接口。
